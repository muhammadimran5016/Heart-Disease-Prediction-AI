# ❤️ HeartCare AI – Heart Disease Prediction System

## 🩺 Overview

Heart Disease Prediction AI is an AI-powered Heart Disease Prediction System developed using Machine Learning and Streamlit. The application predicts the likelihood of heart disease based on patient clinical information and provides interactive visualizations, confidence scores, and personalized health recommendations.

This project demonstrates the practical application of Artificial Intelligence in healthcare by combining predictive analytics with an intuitive web interface.

## 🧠 Machine Learning Models

The following models were trained and evaluated:

- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest Classifier

After comparing performance, the best-performing model was selected as the final deployed model.

## 📂 Dataset

**Dataset:** UCI Heart Disease Dataset

The dataset contains important clinical features including:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression
- Slope
- Number of Major Vessels
- Thalassemia

## 🚀 Installation

1. **Clone the repository**
```bash
git clone https://github.com/muhammadimran5016/Heart-Disease-Prediction-AI.git
```

2. **Move into the project**
```bash
cd Heart-Disease-Prediction-AI
```

3. **Install dependencies**
```bash
pip install -r requirements.txt
```

4. **Run the Streamlit application**
```bash
streamlit run app/app.py
```
